# 🔥 Algerian Forest Fires — EDA, Feature Engineering & Machine Learning

## 📌 Project Overview

This project analyzes the **Algerian Forest Fires dataset** to understand how environmental and weather conditions influence forest fire occurrence.

The project follows a complete **Data Science and Machine Learning workflow**, starting from data cleaning and exploratory data analysis (EDA), followed by feature engineering and machine learning model training.

The main objective is to identify important patterns and relationships in the dataset that can help in understanding and predicting forest fire risk.

---

## 🎯 What Does This Project Do?

This project performs the following tasks:

* Loads and explores the Algerian Forest Fires dataset
* Cleans and preprocesses raw data
* Handles missing and inconsistent values
* Performs Exploratory Data Analysis (EDA)
* Analyzes relationships between weather conditions and forest fires
* Creates useful features through Feature Engineering
* Visualizes important patterns using graphs and charts
* Prepares the dataset for Machine Learning
* Trains Machine Learning models to predict forest fire-related outcomes
* Evaluates model performance

---

## 🌲 Dataset

The project uses the **Algerian Forest Fires dataset**, containing weather and environmental observations from two regions of Algeria:

* **Bejaia**
* **Sidi Bel-Abbes**

The dataset contains variables related to:

* Temperature
* Relative Humidity
* Wind Speed
* Rainfall
* Fire Weather Index (FWI)
* FFMC
* DMC
* DC
* ISI
* BUI
* Fire/Not Fire class

These variables help analyze the environmental conditions associated with forest fires.

---

## 🔍 Exploratory Data Analysis (EDA)

EDA is used to understand the dataset before applying Machine Learning.

The analysis includes:

* Data structure and data types
* Statistical summary
* Missing value analysis
* Duplicate checking
* Distribution analysis
* Correlation analysis
* Outlier analysis
* Univariate analysis
* Bivariate analysis
* Multivariate analysis
* Relationship between weather conditions and fire occurrence

Visualization helps identify which environmental factors have stronger relationships with forest fire activity.

---

## ⚙️ Feature Engineering

Feature Engineering is performed to transform the raw dataset into a more useful format for Machine Learning.

This includes:

* Selecting relevant features
* Removing unnecessary columns
* Converting categorical variables
* Creating meaningful derived features
* Preparing independent and dependent variables
* Feature scaling where required

The goal is to provide better-quality input features to the Machine Learning models.

---

## 🤖 Machine Learning

After data preprocessing and feature engineering, the prepared dataset is used for Machine Learning model training.

The project includes a separate **Model Training** notebook where the processed data is used to build and evaluate predictive models.

The models help determine whether weather and environmental conditions can be used to identify forest fire risk.

Forest fires can cause significant environmental and economic damage.

This type of analysis can be useful for:

* 🔥 Understanding forest fire patterns
